实际变量名以思源当前版本主题系统为准。下方为文档站自身使用的变量名风格示例，**仅作版式参考**，与思源主程序不一定一致。

## 示例（本站 `global.css` 风格）

- **`--text` / `--text-secondary`**：主文与次要文字
- **`--border` / `--border-strong`**：细线与强调边线
- **`--bg-subtle`**：弱背景与悬停底
- **`--accent`**：高亮与侧栏当前项强调色

正式写作时请改为从源码或官方主题中摘抄的真实变量表，并注明最低支持版本。
