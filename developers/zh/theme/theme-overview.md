思源主题通常包含 CSS 与资源文件，通过 CSS 变量与选择器覆盖界面样式。本页为占位，用于展示「主题」分组与版式。

## 包内常见内容

- 根目录下的 `theme.json` 或约定清单（以实际规范为准）
- 样式入口与分片（如按组件拆分）
- 字体、图标等静态资源

## 与插件的区别

主题侧重 **呈现层** 与 **CSS 变量**；插件侧重 **行为** 与 **API**。二者可配合：主题提供变量名，插件在适当时机改 DOM 或类名（需谨慎，避免与主题更新冲突）。
