This is an **Astro static site** demo aligned with a “white background, black text, thin borders” layout. Body text is generated from Markdown and can later be swapped for **Lute** output from SiYuan.

## Local commands

```bash
cd site && pnpm dev
```

## Deployment

Build output lives in `site/dist` and can be deployed to **GitHub Pages** (a workflow is reserved in the repo; in Settings → Pages choose the GitHub Actions source).
