## Examples (this site’s `global.css` style)

- **`--text` / `--text-secondary`**: Primary and secondary text
- **`--border` / `--border-strong`**: Hairlines vs stronger borders
- **`--bg-subtle`**: Subtle backgrounds and hover fills
- **`--accent`**: Highlights and the sidebar active item
