# 版权与致谢

Diátaxis 由 [Daniele Procida](https://vurt.eu) 创立并撰写。

它经过多年发展，仍在持续扩展与探索。

## 联系我

欢迎 [给我发邮件](mailto:daniele@vurt.org)。我很喜欢听到别人使用 Diátaxis 的经历，也会阅读收到的每一封信。

感谢大家的关注，我会尽力回复；但与 Diátaxis 相关的邮件数量相当大，我无法承诺回复每一条。

如果你想与其他用户讨论 Diátaxis，请到 [Write the Docs Slack](https://www.writethedocs.org/slack/) 上的 *#diataxis* 频道，或访问本网站 GitHub 仓库的 [Discussions](https://github.com/evildmp/diataxis-documentation-framework/discussions) 区：[GitHub 仓库](https://github.com/evildmp/diataxis-documentation-framework)。

## 起源与发展

你可以在这里找到 [这些想法的早期呈现版本之一](https://documentation.divio.com)：那是我在 Divio 工作期间（2014–2021）整理的。其中大多数内容我仍认同，尽管也有一些方面我现在觉得自己当初弄错了。

Diátaxis 最初的情境主要限于软件产品文档。

2021 年，我获得了 [Software Sustainability Institute](http://software.ac.uk/blog/sorry-state-usable-software-open-science-results-open-science-retreat) 的 Fellowship，以探索它在科学研究情境中的应用。近来我还探索了它在企业内部文档、组织管理与教育中的应用，以及规模化应用；相关工作仍在进行。

也有人写信与我分享：他们把 Diátaxis 应用到笔记系统，甚至作为家庭事务管理的系统化方法的一部分。

## 引用与贡献

若要引用 Diátaxis，请参阅 [本网站 diataxis.fr](https://diataxis.fr/)。

源代码仓库中包含引用文件 [CITATION.cff](https://github.com/evildmp/diataxis-documentation-framework/blob/main/CITATION.cff)。

APA 与 BibTeX 元数据可在 <https://github.com/evildmp/diataxis-documentation-framework> 的 *Cite this repository* 选项中获取。

你也可以提交 pull request 提出改进或更正，或 [提交 issue](https://github.com/evildmp/diataxis-documentation-framework/issues)。

Diátaxis 现已在数百个项目中使用；我已无法再逐一响应“把某某项目列入采用示例”的请求。
