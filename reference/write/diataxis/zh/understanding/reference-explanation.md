# 参考与阐释的差别

阐释与参考都属于 Diátaxis 地图上*理论*那一半——它们不包含引导读者的步骤，承载的是理论知识。

二者之间的差别——与教程和操作指南之间的差别一样——在于技能与知识是*习得*还是*运用*。换言之，就是*学习*与*工作*之分。

## 大多时候还算直白

多数情况下，辨认手头究竟是哪一种并不太难。*参考*作为一种写法，我们从小就常在写作的区分里用到。

何况文本实例本身也常泾渭分明。潮位表配上数字表格，显然是参考材料；一篇文章若解释*为何*有潮汐、潮汐如何变化，则不言而喻是阐释。

实用的经验法则包括：

- **若它沉闷又难记**，多半是*参考*。
- **事物清单**（例如类、方法、属性）以及**信息表**，一般可归入*参考*。
- 反过来说，**若能想象在浴缸里读它**，那多半是*阐释*（虽说人们在浴缸里读什么实在难以预料）。

不妨设想散步或喝东西时问朋友：**能多讲讲某个主题吗？**——随后的回答或讨论，多半就是对它的*阐释*。

### ……但直觉并不总是靠得住

多数时候我们可以放心凭直觉区分参考与阐释。但也只是*多数时候*——因为两种形式也很容易彼此滑移。

这通常发生在参考写得越来越铺陈的时候。例如，在参考里加入示例完全合理（正如百科全书也可以配图）——但示例写起来有趣，很容易越写越像阐释（借示例讲*为什么*、*万一怎样*、由来如何）。

于是常见阐释性片段零星掉进参考里。这对参考有害：叙述被打断、主旨被遮蔽。对阐释也有害：它得不到充分展开，无法独立完成自己的工作。

## 工作与学习

若仍存疑，真正的试金石是：人们会不会在*干活时*、在真正做事、执行任务之下去翻它？还是离开工作台之后、想要想一想的时候才需要它？

这是读者两种截然不同的*需求*，反映此刻读者相对于这门技艺，是处在一层*工作*关系还是*学习*关系之中。

> 为避免被直觉误导，请参阅 [指南针](../four-modes/compass.md)。

**参考**是用户在工作时*运用*知识与技能所需要的材料。

**阐释**则是人们为*习得*知识与技能而求助的材料——也就是「学习」。

理解这两种关系，并回应其中的需求，是写好参考与阐释的关键。
