# 地图

Diátaxis 在组织文档时之所以有效，原因之一是它描述的是**二维结构**，而不是一份*清单*。

<img src="https://www.diataxis.fr/_images/diataxis.png" class="sidebar" alt="" />

它对文档类型的规定方式，使结构能够自然地引导并塑造其承载的内容。

作为一张地图，它把不同形式的文档摆进彼此的关系里。每一种都在它勾画的心智版图上占据一席之地，它们之间的边界则凸显其差异。

## 结构之难

当文档没有形成良好的结构时，问题往往不只在结构本身（尽管单这一点就已让使用与维护都更困难）。结构上的缺陷会感染、削弱内容。

在缺乏清晰、可泛化的文档体系时，写作者常常只好按产品功能来组织材料。

这很少能成功，即便只考虑单一产品。在成组的文档站里，结果更是各行其是。远为更可取的是采用一种试图回答这一问题的方案：*一般而言*，文档应如何安排？

事实上，任何把文档按清晰的内容类别来梳理的尝试，都会有所帮助（对作者和读者皆然），因为那样就有了内容类型的清单。

即便如此，作者仍常不得不撰写难以塞进既有类别的内容，或痛苦地改写旧稿。人们常感到所依循的结构带有一种随意性：为何是这一组内容类型，而不是另一组？若出现另一套竞争性的分类，又该采信哪一边？

## 期待与引导

以这种方式组织材料，一个明确的优势是：它同时给读者清晰的*期待*，也给作者清晰的*引导*。任一内容的意图一目了然，该怎样写、该放在哪里，都有迹可循。

|  | [教程](../four-modes/tutorials.md) | [操作指南](../four-modes/how-to.md) | [参考](../four-modes/reference.md) | [阐释](../four-modes/explanation.md) |
|----|----|----|----|----|
| 作用 | 引入、教育、带领 | 指引 | 陈述、描述、告知 | 解释、阐明、讨论 |
| 回答的问题 | 「能否教我……？」 | 「我该如何……？」 | 「……是什么？」 | 「为什么……？」 |
| 取向 | 学习 | 目标 | 信息 | 理解 |
| 目的 | 提供学习体验 | 帮助达成特定目标 | 描述机制 | 照亮某一主题 |
| 形态 | 一课 | 一系列步骤 | 干巴巴的说明 | 舒展的阐释 |
| 类比 | 教孩子做饭 | 菜谱里的一道配方 | 食品包装背面的信息 | 关于饮食社会史的一篇文章 |

每一类内容不但有其特定职责，这项职责也与其他文档功能清晰地区分开来、形成对照。

## 模糊地带

大多数文档体系与作者至少承认其中若干区分，并在实践中尽量遵守。

<img src="https://www.diataxis.fr/_images/partial-collapse.png" class="sidebar"
alt="结构的局部坍缩" />

然而，地图上相邻的不同文档形式之间总有一种天然的亲缘，区分也总有一种被抹平的倾向（在各类文档实例里反复可见）。

|                                 |           |               |
|---------------------------------|-----------|---------------|
| 引导行动                    | 教程 | 操作指南 |
| 服务于技能的运用  | 参考 | 操作指南 |
| 承载命题性知识 | 参考 | 阐释   |
| 服务于技能的习得  | 教程 | 阐释   |

若听任这些区分模糊，不同种类的文档就会彼此渗透。文风与内容会闯入不该出现的位置，结构问题也随之加剧，使「按恰当文体写作」的纪律更难维持。

<img src="https://www.diataxis.fr/_images/total-collapse.png" class="sidebar"
alt="结构的完全坍缩" />

最坏的情形下，教程与操作指南会完全或部分塌缩成彼此不分，使得二者所要满足的需求都无法兑现。

## 绕地图而行

Diátaxis 旨在帮助文档更好地服务于用户与产品之间*交互循环*中的需求。

这话不宜理解得过于字面：并不是说用户必须按 *教程* → *操作指南* → *技术参考* → *阐释* 的顺序接触文档。实际上，用户会从任意位置进入文档以寻找某一主题的指引，而在使用文档的过程中，他们想读的东西也会时刻变化。

不过，「文档需求沿不同阶段循环」这一观念是站得住脚的，也符合人们如何在技艺上真正变得精通。这种排序自有其意义与内涵。

<img src="https://www.diataxis.fr/_images/map-movement.png" class="sidebar"
alt="在地图上游移" />

- *面向学习的阶段*：我们从学习开始；而学习一项技能，就意味着直接动手去做——若运气好，还有教师指点。
- *面向目标的阶段*：接着我们想把技能用起来。
- *面向信息的阶段*：一旦工作仰赖我们脑中尚未装下的知识，就需要查阅技术参考。
- *面向阐释的阶段*：最后，离开工作台之后，我们回顾实践与知识，以理解整体。

然后又回到起点——也许是去掌握一件新事物，或是理解得更深一层。
