# 理解 Diátaxis

> 文档的大统一理论
>
> — David Laing

------------------------------------------------------------------------

本节中的页面旨在为 Diátaxis 所倡导的实践提供一定的理论基础，并探讨由此引出的一些问题。

在文档这一学科里，论述往往偏向实用与具体。常见做法是启发式的：指南、经验法则、明确的命令、我们已知有效的原则。

作为实践者，我们有很多关于「做什么」「如何做」「它如何生效」可讲，却很少谈*为什么*它会生效。我们对「正确做法」的感觉，多半来自直觉与经验的混合；学科中理论面向得到的关注要少得多。

Diátaxis 旨在把文档实践置于更严谨的理论基础之上。
