# 应用 Diátaxis

本节中的页面讨论如何把 Diátaxis 付诸实践。

> Diátaxis 建立在 [系统化的理论基础](../understanding/theory.md) 之上，但要有效使用这套方法，并不一定需要先理解这些理论。

Diátaxis 首先是为从事文档工作的人准备的务实方法。要把它在实践中用好，大多数关键原则都可以凭直觉把握。

不要等到“完全理解 Diátaxis”之后才开始尝试应用。你不仅不必先搞懂一切就能用起来；而且在你开始用它之前，你也并不会真正理解它（这本身也是 Diátaxis 的一条原则）。

一旦你感到某个想法值得应用到工作中，就去试。需要更多澄清或安心感时，再回到这里。在你的工作与对工作反思之间来回迭代。

## 本节内容

Diátaxis 的核心是它辨认出的四种不同文档类型。如果你是第一次接触 Diátaxis，从这些页面开始：

- [教程](../four-modes/tutorials.md) —— 面向学习体验的文档
- [操作指南](../four-modes/how-to-guides.md) —— 面向目标与步骤的文档
- [参考](../four-modes/reference.md) —— 面向信息与事实的技术描述
- [阐述说明](../four-modes/explanation.md) —— 面向理解与讨论的文档

Diátaxis 给出指导行动的原则；这些原则会转化为具体的工作方式，并对文档流程与执行产生影响。一旦你迈出第一步，这里概述的工具与方法会让路径更顺畅。

- [指南针](../four-modes/compass.md) —— 一个简单的定向工具
