# 指南针

<img src="https://diataxis.fr/images/diataxis.png" class="sidebar" alt="" />

Diátaxis 地图能有效提醒人们文档有哪些类型、彼此如何关联，也与人们对文档的直觉颇为一致。

然而直觉并不总是可靠。撰写文档时，作者常常会面对这样的问题：*这属于哪一种文档？* 或 *这里需要哪一种文档？* —— 却没有明显、直觉式的答案。

更糟的是，有时直觉立刻给出的答案还是错的。

在不熟悉的地形里，地图若再配上指南针，才最有力量。

Diátaxis 指南针有点像文档的**真值表**或**决策树**。它把一个更复杂的二维问题拆成更简单的部分，并为作者提供纠偏工具。

| 若内容…… | ……且服务于用户的…… | ……则它应归入…… |
|-----------|---------------------|----------------|
| 指导行动 | 技能的**习得** | 教程 |
| 指导行动 | 技能的**运用** | 操作指南 |
| 传达认知 | 技能的**运用** | 参考手册 |
| 传达认知 | 技能的**习得** | 阐释 |

指南针既可用于需要文档的**用户情境**，也可用于**文档本身**——例如某段内容或许需要挪动或改进。和许多好工具一样，它出奇地朴素。

使用指南针时，只需问两个问题：*行动还是认知？* *习得还是运用？*

然后就能得到答案。

## 使用指南针

当你（或眼前的文档）自以为在做一件事，却又被疑虑或工作中的某种困难所困扰时，指南针特别有效。它会迫使你停下来重新考虑。

尤其在试图确定**最初方位**时，请灵活使用指南针里的术语；不要死抠具体名称。

- *行动*：实际步骤、动手去做
- *认知*：命题式或理论知识、思考
- *习得*：学习、钻研
- *运用*：工作、实践

问题本身也可以换几种问法：

- 我认为自己在为 *x* 还是 *y* 而写？
- 眼前的文字是在做 *x* 还是 *y*？
- 用户需要的是 *x* 还是 *y*？
- 我想 *x* 还是 *y*？

试着在**句子和词语**的细粒度上运用它们，也可以从更宏观的角度，审视整篇文档。
