# Diátaxis

**一种系统化的技术文档写作思路。**

------------------------------------------------------------------------

Diátaxis 是一种看待文档、撰写文档的方式。

它从系统化理解文档用户需求出发，对内容、架构与形式给出可操作的指引。

Diátaxis 区分四种彼此不同的需求，以及与之对应的四种文档形态 —— *教程（tutorials）*、*操作指南（how-to guides）*、*技术参考（technical reference）* 与 *阐述说明（explanation）*。它把这四种形态放进一套系统化的相互关系中，并主张文档自身的组织方式也应围绕这些需求结构来展开。

![Diátaxis](https://www.diataxis.fr/_images/diataxis.png)

> *Diátaxis* 一词来自古希腊语 δῐᾰ́τᾰξῐς：*dia*（“贯穿、横跨”）与 *taxis*（“排列、安排”）。

Diátaxis 针对的是文档 *内容*（写什么）、*风格*（怎么写）与 *架构*（如何组织）方面的问题。

除了服务文档读者之外，Diátaxis 对文档作者与维护者也有价值：它轻量、易上手、易于落地；不强加实现层面的约束；还为文档带来一种积极的质量原则，帮助维护者更清晰地反思自己的工作。
