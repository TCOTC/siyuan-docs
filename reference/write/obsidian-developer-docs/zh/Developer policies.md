我们希望社区插件与主题既能方便用户安全地修改与扩展 Obsidian 的能力，又优先保障应用的私密与离线使用。

所有加入 Obsidian 目录的社区插件与主题都必须遵守下列政策。每个插件与主题在纳入目录前都会单独审核。不符合政策的插件与主题将从目录中移除。

这些政策仅适用于列入官方 Obsidian 目录的插件。安装在目录之外的插件不受这些政策约束，但它们仍然是值得遵循的良好实践。

另请阅读 [[Submission requirements for plugins]]。
## 政策

### 不允许的行为

插件与主题不得：

- 混淆代码以隐瞒用途。
- 插入通过互联网加载的动态广告。
- 在插件自有界面之外插入静态广告。
- 包含客户端遥测（telemetry）。
- 包含用于更新插件本身的机制。
- 主题不得从网络加载资源。若要打包资源，请参阅 [[Embed fonts and images in your theme|本指南]]。

### 披露事项

下列情形仅在 README 中清楚说明时才允许：

- 完整功能需要付费。
- 完整功能需要账户。
- 使用网络。须清楚说明使用了哪些远程服务以及为何需要。
- 访问 Obsidian 库以外的文件。须清楚说明为何需要。
- 插件自有界面内的静态广告，如横幅与弹出消息。
- 服务端遥测。必须附上隐私政策链接，说明数据的处理方式。
- 闭源代码。将按个案处理。

### 版权与许可

所有社区插件与主题必须满足下列要求：

- 包含 [LICENSE 文件](https://docs.github.com/en/communities/setting-up-your-project-for-healthy-contributions/adding-a-license-to-a-repository)，并在其中清楚标明插件或主题的许可证。
- 遵守插件或主题所用任何代码的原始许可要求；若须署名，请在 README 中注明。
- 遵守 Obsidian 的商标政策。不得以可能让用户误以为插件或主题为官方作品的方式使用 「Obsidian」 商标。

## 举报违规

若你发现某插件或主题违反上述政策，请在该作者的仓库中新建 GitHub issue 告知开发者。请先查看是否已有相同反馈。

若开发者 7 天内未回应，请[联系 Obsidian 团队](https://help.obsidian.md/Help+and+support#Report+a+security+issue)。对于严重违规，你可以立即联系团队。

## 移除插件与主题

若存在政策违规，我们可能会联系开发者，并给予合理期限以解决问题。

若到期仍未解决，我们会将相应插件或主题从目录中移除。

在下列情况下，我们可能立即移除插件或主题：

- 插件或主题疑似恶意。
- 开发者拒不配合。
- 属于屡次违规。

此外，我们也可能移除已无人维护或严重损坏的插件或主题。
