# Obsidian 开发者文档

欢迎使用 Obsidian 官方开发者文档，你可以在这里学习如何为 [Obsidian](https://obsidian.md/) 构建插件与主题。若要了解如何使用 Obsidian，请访问[官方帮助站点](https://help.obsidian.md/)。

## 插件

使用 TypeScript 编写插件，扩展 Obsidian 的现有功能。

- [[Build a plugin|构建你的第一个插件]]
- [[Submit your plugin]]

## 主题

使用 CSS 为 Obsidian 设计主题与代码片段。

- [[Build a theme|构建你的第一个主题]]
- [[Submit your theme]]
- [[CSS variables]]

## 加入开发者社区

若遇到问题或希望获得反馈，请[加入社区](https://obsidian.md/community)。

- Discord 上的 `#plugin-dev` 与 `#theme-dev` 频道。
- 论坛上的 [Developers & API](https://forum.obsidian.md/c/developers-api/14) 与 [Share & showcase](https://forum.obsidian.md/c/share-showcase/9)。

## 参与贡献

若你发现本站有误或可改进之处，或希望提交 PR，欢迎在 [我们的 GitHub 仓库](https://github.com/obsidianmd/obsidian-developer-docs) 中新建 issue。
更多说明见仓库 [readme](https://github.com/obsidianmd/obsidian-developer-docs#readme)。

预先感谢你的贡献！
