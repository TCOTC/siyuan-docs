本页面描述了清单“manifest.json”的架构。

## 属性

以下属性可用于插件和主题。

|物业 |类型 |必填|描述 |
| ---------------- | ----------------------------------- | -------- | ------------------------------------------------------------------------------------------------ |
| `作者` | `字符串` | **是** |作者姓名。                                                                   |
| `minAppVersion` | `字符串` | **是** |所需的最低黑曜石版本。                                               |
| `名称` | `字符串` | **是** |显示名称。                                                                    |
| `版本` | `字符串` | **是** |版本，使用[语义版本控制](https://semver.org/)，格式为“x.y.z”。 |
| `作者网址` | `字符串` |没有 |作者网站的 URL。                                                       |
| `fundingUrl` | `string` 或 [`object`](#fundingurl) |没有 |用户可以在财务上支持您的项目的一个或多个 URL。      |

## 插件特定的属性

以下属性仅适用于插件。

|物业 |类型 |必填|描述 |
| ---------------- | ---------| -------- | ------------------------------------------------------- |
| `描述` | `字符串` | **是** |您的插件的描述。                           |
| `id` | `字符串` | **是** |您的插件的 ID。 ID 不能包含“obsidian”。 |
| `仅限桌面` | `布尔值` | **是** |您的插件是否使用 NodeJS 还是 Electron API。       |

> [!note]
> 对于本地开发，`id`应该与插件的文件夹名称匹配；否则某些方法，例如`onExternalSettingsChange`，将不会被调用。

## 资金网址

“fundingUrl”可以是具有单个 URL 的字符串，也可以是具有多个 URL 的对象。

**单一网址**：

```json
{
  "fundingUrl": "https://buymeacoffee.com"
}
```

**多个 URL**：

```json
{
  "fundingUrl": {
    "Buy Me a Coffee": "https://buymeacoffee.com",
    "GitHub Sponsor": "https://github.com/sponsors",
    "Patreon": "https://www.patreon.com/"
  }
}
```
