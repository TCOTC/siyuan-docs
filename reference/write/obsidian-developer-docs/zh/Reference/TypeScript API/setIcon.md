## setIcon() 函数

将 SVG 从 iconId 插入到元素中。如果没有与 iconId 关联的图标，则不执行任何操作。

**签名：**

```typescript
export function setIcon(parent: HTMLElement, iconId: IconName): void;
```## 参数

|  参数|类型 |描述 |
|  --- | --- | --- |
|  <code>父</code> | <code>HTMLElement</code> |用于插入图标的 HTML 元素 |
|  <code>iconId</code> | [`图标名称`](图标名称) |图标ID |

**退货：**

`无效`
