此页面列出了 [侧边栏](https://help.obsidian.md/User+interface/Workspace/Sidebar) 的 CSS 变量。

## CSS 变量

|变量|描述 |
| ------------------------------------------ | ------------------------------------------- |
| `--sidebar-markdown-font-size` |侧边栏中 Markdown 文件的字体大小 |
| `--sidebar-tab-text-display` |侧边栏中选项卡文本的“display”属性 |
