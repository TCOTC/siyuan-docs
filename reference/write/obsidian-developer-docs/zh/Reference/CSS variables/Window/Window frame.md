此页面列出了窗口框架的 CSS 变量，包括标题栏。

> [!note]
> 要看到标题栏，您需要将**设置→外观→窗框样式**更改为**黑曜石框**。

## CSS 变量

|变量|描述 |
| ------------------------------------------- | ------------------------------------------------------ |
| `--标题栏背景` |标题栏背景颜色|
| `--标题栏背景聚焦` |标题栏背景颜色（聚焦窗口）|
| `--标题栏边框宽度` |标题栏边框宽度|
| `--标题栏边框颜色` |标题栏边框颜色 |
| `--标题栏文本颜色` |标题栏文字颜色 |
| `--标题栏文本颜色聚焦` |标题栏文本颜色（聚焦窗口）|
| `--标题栏文本权重` |标题栏字体粗细 |
| `--标题高度` |框架元素的默认高度 |
