此页面列出了 [Ribbon](https://help.obsidian.md/User+interface/Workspace/Ribbon) 的 CSS 变量。

## CSS 变量

|变量|描述 |
| ------------------------------------------- | ------------------------------------------- |
| `--丝带背景` |丝带背景颜色|
| `--ribbon-background-collapsed` |功能区背景颜色（折叠侧边栏）|
| `--ribbon-width` |色带宽度|
| `--ribbon-padding` |丝带衬垫|
