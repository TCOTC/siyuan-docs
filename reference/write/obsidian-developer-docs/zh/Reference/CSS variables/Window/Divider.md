此页面列出了分隔线的 CSS 变量以及调整侧边栏、选项卡和分割窗格之间的手柄大小。

## CSS 变量

|变量|描述 |
| ------------------------ | | ---------------------------- |
| `--分隔线颜色` |分隔线边框颜色 |
| `--divider-color-hover` |分隔线边框颜色（悬停）|
| `--分隔符宽度` |分隔线边框宽度|
| `--divider-width-hover` |分隔线边框宽度（悬停）|
| `--divider-vertical-height` |分隔线垂直高度|
