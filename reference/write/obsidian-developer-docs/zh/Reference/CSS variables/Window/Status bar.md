本页列出了[状态栏](https://help.obsidian.md/User+interface/Workspace/Status+bar)的CSS变量。

## CSS 变量

|变量|描述 |
| -------------------------------------- | ------------------------------------------ |
| `--状态栏背景` |状态栏背景颜色|
| `--状态栏边框颜色` |状态栏边框颜色|
| `--状态栏边框宽度` |状态栏边框宽度|
| `--状态栏字体大小` |状态栏字体大小|
| `--状态栏文本颜色` |状态栏文字颜色|
| `--状态栏位置` |状态栏`position`属性|
| `--状态栏半径` |状态栏半径|
| `--状态栏滚动填充` |状态栏滚动填充|
