此页面列出了主侧边栏底部的 **Vault 配置文件** 组件的 CSS 变量。

## CSS 变量

|变量|描述 |
| --------------------------------- | -------------------------------------------------------------------------- |
| `--vault-profile-显示` | Vault 配置文件的“display”属性 |
| `--vault-profile-actions-display` | Vault 配置文件中操作按钮的“display”属性 |
| `--vault-profile-font-size` |字体大小|
| `--vault-profile-font-weight` |字体粗细|
| `--vault-profile-color` |文字颜色 |
| `--vault-profile-color-hover` |文本颜色（悬停）|
