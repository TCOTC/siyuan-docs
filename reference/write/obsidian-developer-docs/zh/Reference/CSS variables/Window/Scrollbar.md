此页面列出了非本机滚动条的 CSS 变量。

> [!note]
> 自定义滚动条仅在 Windows 和 Linux 上使用。

## CSS 变量

|变量|描述 |
| -------------------------------------- | ---------------------------------------------------- |
| `--scrollbar-bg` |滚动条背景颜色|
| `--scrollbar-thumb-bg` |滚动条拇指背景颜色|
| `--scrollbar-active-thumb-bg` |滚动条拇指背景颜色（活动）|
