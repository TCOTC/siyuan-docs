## 字体

|变量|描述 |
| ------------------------ | -------------------------------------------------------------------------------- |
| `--字体界面主题` | UI 元素使用的字体 |
| `--字体文本主题` |编辑器中文本使用的字体 |
| `--font-monospace-theme` |用于等宽内容（例如代码块和内联代码）的字体 |

## 字体大小

Obsidian 根据上下文使用相对和固定字体大小。

- 在编辑器中使用“--font-*”（相对）变量。
- 对 UI 元素使用 `--font-ui-*` （固定）变量。

|变量|默认值 |描述 |
| ------------------- | ------------- | ---------------------------------------------------------------- |
| `--字体文本大小` | `16 像素` |编辑器字体大小。由用户在外观设置下定义。 |
| `--字体最小` | `0.8em` |                                                                  |
| `--字体较小` | `0.875em` |                                                                  |
| `--小字体` | `0.933em` |                                                                  |
| `--font-ui-smaller` | `12px` |                                                                  |
| `--font-ui-small` | `13px` |                                                                  |
| `--font-ui-medium` | `15 像素` |                                                                  |
| `--font-ui-large` | `20 像素` |                                                                  |

## 文本格式

从 Obsidian 1.6 开始，推荐使用“--bold-modifier”来更改粗体文本的粗细。粗体修饰符值堆叠在其他字体粗细之上。这允许已经加粗的文本具有更重的粗细，例如`## 大胆 **更大胆**`。 `--bold-modifier` 的建议值在 100 到 300 之间。

|变量|描述 |
| ----------------- | ---------------------------- |
| `--字体粗细` |常规文本粗细 |
| `--粗体修饰符` |增加粗体文本的粗细 |
| `--粗体` |粗体文本字体粗细 |
| `--粗体颜色` |粗体文字颜色 |
| `--斜体颜色` |斜体文字颜色 |

## 行高

|变量|默认值 |描述 |
| ---------------------- | ------------- | ---------------------------------------------------------------------------------- |
| `--行高-正常` | `1.5` |默认行高 |
| `--行高-紧` | `1.3` |用于搜索结果、树项目、工具提示和其他较小的空间 |

| ------------------- | -------------------------- |
| `--标题间距` |标题上方的间距 |
