Obsidian 使用 4 像素网格来构建 UI 元素。通过使用 4 的倍数作为填充和边距，网格为布局提供了方便的比例，并允许界面在高 DPI 和低 DPI 屏幕上按比例放大和缩小。

为了与 4 像素网格对齐，所有元素都应使用预定义的“--size” CSS 变量作为间距和尺寸属性。

每个大小变量包含两个数字，分别代表基数和倍数。

- `--size-4-1` 代表 `4px` (4x1)
- `--size-4-2` 代表 `8px` (4x2)
- `--size-4-4` 代表 `16px` (4x4)

除了 4 像素网格之外，Obsidan 还提供了一组使用 2 像素网格的变量。仅当您需要更细粒度的间距时才谨慎使用这些。

|变量|默认值 |
| ------------- | ------------- |
| `--size-2-1` | `2px` |
| `--size-2-2` | `4px` |
| `--size-2-3` | `6 像素` |
| `--size-4-1` | `4px` |
| `--size-4-2` | `8 像素` |
| `--size-4-3` | `12px` |
| `--size-4-4` | `16 像素` |
| `--size-4-5` | `20 像素` |
| `--size-4-6` | `24 像素` |
| `--size-4-8` | `32 像素` |
| `--size-4-9` | `36 像素` |
| `--size-4-12` | `48 像素` |
| `--size-4-16` | `64 像素` |
| `--size-4-18` | `72 像素` |
