图标一目了然地传达信息，并引起人们对重要信息的注意。

Obsidian 使用 [Lucide](https://lucide.dev/) 图标库，其中包含 800 多个图标。您可以在他们的网站上找到所有可用的图标。

> [!important] 自定义图标
> 如果您想为Obsidian创建自己的图标，则需要遵循[图标设计原则](https://lucide.dev/guide/design/icon-design-guide)。您可以找到适用于 Illustrator、Figma 和 Inkscape 等矢量编辑器的[模板和指南](https://github.com/lucide-icons/lucide/blob/main/CONTRIBUTING.md)。

|变量|描述 |
| ---------------------------------- | ----------------------------------- |
| `--图标大小` |图标宽度和长度的简写 |
| `--图标笔划` |图标笔画宽度的简写 |
| `--图标颜色` |图标颜色|
| `--图标颜色悬停` |图标颜色（悬停）|
| `--icon-color-active` |图标颜色（活动）|
| `--以图标颜色为中心` |图标颜色（重点）|
| `--图标不透明度` |图标不透明度|
| `--图标不透明度悬停` |图标不透明度（悬停）|
| `--icon-opacity-active` |图标不透明度（活动）|
| `--clickable-icon-radius` |可点击图标按钮半径|

### 图标大小

|变量|默认值 |
| ------------------------ | ------------- |
| `--icon-xs` | `14 像素` |
| `--icon-s` | `16 像素` |
| `--icon-m` | `18 像素` |
| `--icon-l` | `18 像素` |
| `--icon-xl` | `32 像素` |
| `--icon-xs-笔画宽度` | `2px` |
| `--icon-s-笔划宽度` | `2px` |
| `--icon-m-笔画宽度` | `1.75 像素` |
| `--icon-l-笔画宽度` | `1.75 像素` |
| `--icon-xl-笔画宽度` | `1.25px` |
