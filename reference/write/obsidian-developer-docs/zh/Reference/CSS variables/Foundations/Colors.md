## 强调色

强调色用于引起对交互元素的注意，例如链接和主按钮，并且可以由用户在 Obsidian 应用程序中的 **设置 → 外观** 下覆盖。

|变量|默认值 |描述 |
| ------------ | ------------- | ----------------- |
| `--重音-h` | `254` |强调色调|
| `--重音-s` | `80%` |口音饱和度|
| `--重音-l` | `68%` |强调轻盈|

> [!tip]
> 您可以使用 [CSS 计算](https://developer.mozilla.org/en-US/docs/Web/CSS/calc) 根据强调色创建各种色调。

## 扩展颜色

扩展颜色变量定义了用于状态消息（错误、警告、成功）、标注、语法突出显示、图形节点和 Canvas 元素的更广泛的颜色。

每个扩展颜色都有一个带有“-rgb”后缀的附加 RGB 变量，您可以使用“rgba”函数来创建具有不透明度的颜色。

例如，以下代码片段使用默认变量设置文本颜色，并使用 RGB 变量将背景颜色设置为不透明度为 20% 的红色。

```css
color: var(--color-red);
background-color: rgba(var(--color-red-rgb), 0.2);
```

## 黑白

黑色和白色可让您创建不透明的蒙版。

|变量|默认值（灯光模式）|默认值（深色模式）|
| ---------------- | -------------------------- | ---------------------------------- |
| `--mono-rgb-0` | `255, 255, 255` | `0, 0, 0` |
| `--mono-rgb-100` | `0, 0, 0` | `255, 255, 255` |

> [!warning]
> 避免更改黑白变量的值。
