此页面列出了缩进指南的 CSS 变量。缩进指南可视化嵌套列表中的缩进级别。

## CSS 变量

|变量|描述 |
| ------------------------------------------------ | --------------------------------------- |
| `--缩进指南宽度` |缩进引导边框宽度|
| `--indentation-guide-width-active` |缩进参考线边框宽度（活动）|
| `--缩进指南颜色` |缩进指南边框颜色 |
| `--indentation-guide-color-active` |缩进引导边框颜色（活动）|
| `--缩进指南编辑缩进` |编辑模式下缩进的宽度 |
| `--缩进指南阅读缩进` |读取模式下缩进的宽度 |
| `--缩进指南源缩进` |源模式下缩进的宽度 |
