此页面列出了任务列表内的复选框和文本的 CSS 变量。

## CSS 变量

|变量|描述 |
| -------------------------------- | --------------------------------- |
| `--复选框半径` |半径 |
| `--复选框大小` |高度和宽度|
| `--复选框标记颜色` |支票本身的标记颜色 |
| `--复选框颜色` |背景颜色|
| `--复选框颜色悬停` |背景颜色（悬停）|
| `--复选框边框颜色` |未选中的边框颜色 |
| `--checkbox-border-color-hover` |未选中的边框颜色（悬停）|
| `--checklist-done-decoration` |选中的文字装饰 |
| `--checklist-done-color` |检查文本颜色 |
| `--checkbox-margin-inline-start` | `开始`边距 |
