本页列出了提示的 CSS 变量，例如 [快速切换器](https://help.obsidian.md/Plugins/Quick+switcher) 和 [命令调色板](https://help.obsidian.md/Plugins/Command+palette)。

## CSS 变量

|变量|描述 |
| ----------------------- | -------------------------------------------------- |
| `--提示输入高度` |提示输入高度 |
| `--提示宽度` |提示宽度 |
| `--提示最大宽度` |提示最大宽度（对于窄窗口）|
| `--提示最大高度` |提示最大高度 |
| `--提示边框宽度` |提示边框宽度 |
| `--提示边框颜色` |提示边框颜色 |
