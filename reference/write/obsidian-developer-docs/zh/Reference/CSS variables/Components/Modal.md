此页面列出了模式的 CSS 变量，例如设置窗口和 [[Dialog|dialogs]]。

## CSS 变量

|变量|描述 |
| --------------------------------- | ------------------------------------------------ |
| `--modal-background` |模态背景颜色|
| `--modal-width` |模态默认宽度 |
| `--modal-height` |模态默认高度 |
| `--modal-max-width` |模态最大宽度|
| `--modal-max-height` |模态最大高度|
| `--modal-max-width-narrow` |窄模态最大宽度|
| `--modal-border-width` |模态边框厚度 |
| `--modal-border-color` |模态边框颜色 |
| `--模态半径` |模态半径|
| `--modal-community-sidebar-width` |社区插件/主题侧边栏宽度 |
