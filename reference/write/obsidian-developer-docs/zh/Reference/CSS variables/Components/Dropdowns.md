此页面列出了下拉列表和“select”元素的 CSS 变量。

## CSS 变量

|变量|描述 |
| ---------------------------------- | ------------------------ |
| `--dropdown-background` |背景颜色|
| `--dropdown-背景混合模式` |背景混合模式|
| `--dropdown-background-hover` |背景颜色（悬停）|
| `--dropdown-背景位置` |背景位置|
| `--dropdown-背景大小` |背景尺寸|
| `--dropdown-padding` |衬垫|
