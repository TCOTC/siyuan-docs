此页面列出了多选输入的 CSS 变量。例如，用于列表类型[[Properties]]。

## CSS 变量

|变量|描述 |
| ------------------------ | | -------------------------------------------------- |
| `--药丸颜色` |药丸文字颜色 |
| `--药丸颜色悬停` |药丸文本颜色（悬停）|
| `--药丸颜色删除` |移除时药丸文字颜色 |
| `--pill-color-remove-hover` |移除时的药丸文本颜色（悬停）|
| `--丸装饰` |药丸文字装饰|
| `--药丸装饰-悬停` |药丸文字装饰（悬停）|
| `--药丸背景` |药丸背景颜色|
| `--药丸背景悬停` |药丸背景颜色（悬停）|
| `--药丸边框颜色` |药丸边框颜色 |
| `--药丸边框颜色-悬停` |药丸边框颜色（悬停）|
| `--药丸边框宽度` |药丸边框宽度|
| `--pill-padding-x` |药丸左/右衬垫 |
| `--pill-padding-y` |药丸顶部/底部衬垫 |
| `--药丸半径` |药丸圆角半径 |
| `--药丸重量` |药丸字体粗细|
