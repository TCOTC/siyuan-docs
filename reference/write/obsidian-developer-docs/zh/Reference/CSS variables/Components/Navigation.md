此页面列出了导航项的 CSS 变量，例如 [[File explorer]] 中的文件和文件夹。

## CSS 变量

|变量|描述 |
| -------------------------------------------------- | ------------------------------------------- |
| `--nav-item-size` |导航项字体大小 |
| `--nav-item-color` |导航项文本颜色 |
| `--nav-item-color-hover` |导航项文本颜色（悬停）|
| `--nav-item-color-active` |导航项文本颜色（活动）|
| `--nav-item-color-selected` |导航项文本颜色（选定）|
| `--nav-item-color-highlighted` |导航项文本颜色（突出显示）|
| `--nav-item-background-hover` |导航项背景颜色（悬停）|
| `--nav-item-background-active` |导航项背景颜色（活动）|
| `--nav-item-background-selected` |导航项背景颜色（选定）|
| `--nav-item-padding` |导航项填充 |
| `--nav-item-parent-padding` |父元素的导航项填充 |
| `--nav-item-children-padding-start` |导航项子项“开始”填充 |
| `--nav-item-children-margin-start` |导航项子项“开始”边距 |
| `--nav-item-weight` |导航项字体粗细 |
| `--nav-item-weight-hover` |导航项字体粗细（悬停）|
| `--nav-item-weight-active` |导航项字体粗细（活动）|
| `--nav-item-white-space` |导航项“空白”|
| `--nav-indentation-guide-width` |导航项缩进指南边框宽度|
| `--nav-indentation-guide-color` |导航项缩进指南边框颜色 |
| `--nav-collapse-icon-color` |导航项折叠 V 形颜色 |
| `--nav-collapse-icon-color-collapsed` |导航项折叠 V 形颜色（折叠）|

### 导航标题

导航标题用于可折叠的导航部分，例如反向链接和外链插件中的链接提及。

|变量|描述 |
| ------------------------------------------------ | ---------------------------------------------------- |
| `--nav-标题颜色` |导航标题文本颜色 |
| `--nav-heading-color-hover` |导航标题文本颜色（悬停）|
| `--nav-heading-color-collapsed` |折叠导航标题文本颜色 |
| `--nav-heading-color-colapsed-hover` |折叠导航标题文本颜色（悬停）|
| `--nav-heading-weight` |导航标题字体粗细 |
| `--nav-heading-weight-hover` |导航标题字体粗细（悬停）|
