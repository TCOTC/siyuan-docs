此页面列出了选项卡的 CSS 变量。

## CSS 变量

|变量|描述 |
| ---------------------------------------------------- | -------------------------------------------------------- |
| `--tab-background-active` |选项卡背景颜色（活动选项卡）|
| `--tab-text-color` |选项卡文本颜色 |
| `--tab-text-color-active` |选项卡文本颜色（非焦点窗口，活动）|
| `--tab-text-color-focused` |选项卡文本颜色（聚焦窗口）|
| `--tab-text-color-focused-active` |选项卡文本颜色（聚焦窗口，活动）|
| `--tab-text-color-focused-highlighted` |选项卡文本颜色（聚焦窗口，突出显示）|
| `--tab-text-color-focused-active-current` |选项卡文本颜色（聚焦窗口、当前选项卡）|
| `--tab 字体大小` |选项卡字体大小|
| `--tab-font-weight` |制表符字体粗细 |
| `--tab-container-background` |选项卡容器背景颜色|
| `--tab-divider-color` |选项卡分隔线颜色 |
| `--tab-outline-color` |选项卡轮廓颜色 |
| `--tab-outline-width` |选项卡轮廓宽度 |
| `--tab 曲线` |制表曲线半径|
| `--tab-radius` |标签外半径|
| `--tab-radius-active` |选项卡外半径（活动选项卡）|
| `--tab 宽度` |制表符默认宽度 |
| `--tab-max-width` |选项卡最大宽度 |

### 标签堆栈

堆叠选项卡的样式

|变量|描述 |
| --------------------------------- | -------------------------------------- |
| `--tab-stacked-pane-width` |堆叠窗格宽度 |
| `--tab-stacked-header-width` |堆叠标题宽度 |
| `--tab-stacked-font-size` |堆叠选项卡字体大小 |
| `--tab-stacked-font-weight` |堆叠选项卡字体粗细 |
| `--tab-stacked-text-align` |堆叠选项卡文本对齐 |
| `--tab-stacked-text-transform` |堆叠选项卡文本转换 |
| `--tab-stacked-text-writing-mode` |堆叠选项卡文本书写模式 |
| `--tab-stacked-shadow` |堆叠选项卡阴影 |
