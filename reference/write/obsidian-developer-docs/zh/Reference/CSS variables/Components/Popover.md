此页面列出了弹出窗口和文件预览的 CSS 变量。

## CSS 变量

|变量|描述 |
| ---------------------- | ----------------------- |
| `--popover-width` |弹出框默认宽度 |
| `--popover-高度` |弹出框默认高度 |
| `--popover-最大高度` |弹出窗口最大高度|
| `--popover-字体大小` |弹出窗口字体大小|
| `--popover-pdf-width` | PDF 文件预览宽度 |
| `--popover-pdf-height` | PDF文件预览高度|
