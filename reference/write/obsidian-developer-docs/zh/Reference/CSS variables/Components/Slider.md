本页列出了滑块控件的 CSS 变量。

## CSS 变量

|变量|描述 |
| -------------------------------------- | ------------------------------------------- |
| `--滑块拇指边框宽度` |滑块拇指边框宽度|
| `--滑块拇指边框颜色` |滑块拇指边框颜色 |
| `--滑块拇指高度` |滑块拇指高度|
| `--滑块拇指宽度` |滑块拇指宽度 |
| `--滑块拇指-y` |滑块拇指 Y 位置 |
| `--滑块拇指半径` |滑块拇指半径 |
| `--滑块轨道背景` |滑块轨道背景颜色|
| `--滑块轨道高度` |滑块轨道高度|
