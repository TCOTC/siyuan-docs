此页面列出了 CSS 变量切换。

## CSS 变量

|变量|描述 |
| ---------------------------------- | -------------------------------------- |
| `--切换边框宽度` |切换边框宽度 |
| `--切换宽度` |切换宽度 |
| `--切换半径` |切换半径 |
| `--切换拇指颜色` |切换拇指背景颜色|
| `--切换拇指半径` |切换拇指半径|
| `--切换拇指高度` |切换拇指高度 |
| `--切换拇指宽度` |切换拇指宽度 |
| `--toggle-s-border-width` |小切换边框宽度 |
| `--toggle-s-width` |小肘节宽度|
| `--toggle-s-thumb-height` |小肘节拇指高度|
| `--toggle-s-thumb-width` |小拇指宽度 |
