本页列出了 [Graph view](https://help.obsidian.md/Plugins/Graph+view) 插件使用的 CSS 变量。

## CSS 变量

|变量|描述 |
| ---------------------------------- | -------------------- |
| `--graph-controls-width` |图形控件宽度 |
| `--图形文本` |节点文本颜色 |
| `--图线` |线条颜色 |
| `--graph-node` |解决节点颜色 |
| `--graph-node-unresolved` |未解决的节点颜色 |
| `--以图节点为中心` |聚焦节点颜色 |
| `--graph-node-tag` |标签节点颜色 |
| `--graph-node-attachment` |附件节点颜色 |
