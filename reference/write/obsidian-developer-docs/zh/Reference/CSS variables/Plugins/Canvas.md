本页列出了 [Canvas](https://help.obsidian.md/Plugins/Canvas) 插件使用的 CSS 变量。

## CSS 变量

|变量|描述 |
| ------------------------ | | ---------------------------- |
| `--canvas-background` |画布背景颜色|
| `--canvas-card-label-color` |帆布卡标签文字颜色|
| `--canvas-dot-pattern` |帆布点图案颜色|
| `--canvas-color-1` |帆布卡颜色 1 |
| `--canvas-color-2` |帆布卡颜色 2 |
| `--canvas-color-3` |帆布卡颜色 3 |
| `--canvas-color-4` |帆布卡颜色 4 |
| `--canvas-color-5` |帆布卡颜色 5 |
| `--canvas-color-6` |帆布卡颜色 6 |
