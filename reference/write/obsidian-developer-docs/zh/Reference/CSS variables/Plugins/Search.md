本页列出了 [Search](https://help.obsidian.md/Plugins/Search) 插件使用的 CSS 变量。

## CSS 变量

|变量|描述 |
| -------------------------------------- | ---------------------------------- |
| `--搜索清除按钮颜色` |清除搜索按钮颜色 |
| `--搜索清除按钮大小` |清除搜索按钮大小 |
| `--搜索图标颜色` |搜索放大镜图标颜色|
| `--搜索图标大小` |搜索图标大小|
| `--搜索结果背景` |搜索结果背景颜色 |
