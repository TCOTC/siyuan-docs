当 [[Site navigation]] 打开时，会出现左侧边栏。当**图表**和/或**目录** [[Site components]] 打开时，会出现右侧边栏。当这些组件关闭时，以下变量不起作用。

## CSS 变量

应在“.published-container”上定义特定于发布的变量。

|变量|描述 |
| ------------------------------------------ | ---------------------------------- |
| `--sidebar-left-width` |左侧边栏的宽度 |
| `--sidebar-left-background` |左侧边栏的背景颜色|
| `--sidebar-left-border-width` |左侧边栏右边框宽度 |
| `--侧边栏左边框颜色` |左侧边栏右边框颜色 |
| `--sidebar-right-width` |右侧边栏的宽度 |
| `--sidebar-right-background` |右侧边栏的背景颜色|
| `--sidebar-right-border-width` |右侧边栏左边框宽度 |
| `--侧边栏右边框颜色` |右侧边栏左边框颜色 |
