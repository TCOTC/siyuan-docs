在发布设置中激活时，导航位于左侧边栏中，并且可以使用以下变量设置样式。顶级项目和文件夹的处理方式可以与嵌套项目不同。

## CSS 变量

应在“.published-container”上定义特定于发布的变量。

|变量|描述 |
| --------------------------------- | ------------------------------------------------------ |
| `--nav-collapse-icon-color` |折叠图标颜色|
| `--nav-collapse-icon-color-hover` |折叠图标颜色（悬停）|
| `--nav-parent-item-color` |文件夹和顶级项目的字体颜色 |
| `--nav-parent-item-color-active` |活动顶级项目的字体颜色 |
| `--nav-parent-item-weight` |顶级项目的字体粗细 |
| `--nav-item-color` |嵌套项目的字体颜色 |
| `--nav-item-color-hover` |悬停嵌套项目的字体颜色 |
| `--nav-item-color-active` |活动嵌套项目的字体颜色 |
| `--nav-item-border-color` |嵌套项目的边框颜色 |
| `--nav-item-border-color-hover` |悬停嵌套项目的边框颜色 |
| `--nav-item-border-color-active` |活动嵌套项目的边框颜色 |
| `--nav-item-weight-active` |活动嵌套项目的字体粗细 |
