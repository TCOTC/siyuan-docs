站点标题包含站点徽标（如果在发布设置中添加）、站点名称以及移动汉堡菜单（如果导航已打开）。

在移动设备上以及关闭导航时，网站标题显示为页面顶部的水平标题。在发布设置中打开导航后，站点名称和徽标将显示在左侧边栏中。

此页面列出了用于 Obsidian Publish 站点标题、站点徽标和站点名称的 CSS 变量

## CSS 变量

应在“.published-container”上定义特定于发布的变量。

|变量|描述 |
| ------------------------------------------ | ------------------------------------------ |
| `--标志宽度` |徽标默认宽度 |
| `--标志高度` |标志默认高度|
| `--logo-最大宽度` |标志最大宽度|
| `--logo-最大高度` |标志最大高度|
| `--logo-radius` |标志圆角半径|
| `--标题高度` |网站标题的高度 |
| `--站点名称颜色` |网站名称颜色 |
| `--站点名称颜色悬停` |网站名称悬停颜色 |
| `--站点名称字体` |网站名称字体系列|
| `--站点名称大小` |网站名称字体大小|
| `--站点名称-权重` |网站名称字体粗细 |
| `--站点菜单图标颜色` |手机菜单图标颜色|
| `--站点菜单图标颜色悬停` |移动菜单悬停图标颜色|
| `--站点菜单图标大小` |手机菜单图标大小|
