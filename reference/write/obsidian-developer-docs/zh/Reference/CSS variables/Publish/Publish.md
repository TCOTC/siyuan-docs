### 简介

Obsidian 应用程序中使用的许多 [[CSS variables]] 也可以通过相应的选择器在 Obsidian 发布 (Publish) 中使用。但是，为了满足 Publish 的不同要求，本节中的变量是专门为 Publish 创建的，并将插入到 .published-container 选择器中。 

请参阅[[Build a Publish theme]]了解更多详情。
