此页面列出了用于 Obsidian Publish 站点组件的 CSS 变量。

## CSS 变量

应在“.published-container”上定义特定于发布的变量。

### 组件标题

当在站点设置中打开这些组件时，这些组件上方的标题样式，例如**反向链接**、**图表**、**目录**。

|变量|描述 |
| -------------------------------------- | --------------------------------- |
| `--组件标题颜色` |字体颜色|
| `--组件标题字体` |字体家族 |
| `--组件标题大小` |字体大小 |
| `--组件标题样式` |字体样式，例如普通或斜体|
| `--组件标题变换` |文本转换，例如大写|
| `--组件标题变体` |字体变体 |
| `--组件标题权重` |字体粗细|

### 大纲

在“发布”设置中激活时，右侧边栏中会显示一个目录，显示页面上的可导航标题列表。

|变量|描述 |
| --------------------------------- | -------------------------------- |
| `--大纲标题颜色` |非活动标题的字体颜色 |
| `--大纲标题颜色悬停` |悬停标题的字体颜色 |
| `--outline-heading-color-active` |活动标题的字体颜色 |
| `--outline-heading-weight-active` |活动标题的字体粗细 |

### 图

可以在发布设置中打开图形组件。继承的 CSS 中存在更多用于节点和线条颜色的图形 CSS 变量。

|变量|描述 |
| ---------------- | -------------------------------------- |
| `--图高度` |图形组件的高度 |
