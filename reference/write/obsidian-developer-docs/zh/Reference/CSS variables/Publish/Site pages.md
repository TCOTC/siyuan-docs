此页面列出了用于 Obsidian Publish 页面的 CSS 变量。

## CSS 变量

应在“.published-container”上定义特定于发布的变量。

### 页面宽度和填充

|变量|描述 |
| ----------------------- | ---------------------------------------------------------- |
| `--页面宽度` |可读行宽打开时注释的宽度 |
| `--页面填充` |注释周围的填充 |

### 页面标题

注释标题显示在页面顶部。可以使用“**隐藏页面标题**”选项在发布网站设置中隐藏此标题。

|变量|描述 |
| -------------------------- | --------------------------------- |
| `--页面标题颜色` |字体颜色|
| `--页面标题字体` |字体系列，请参阅[[Site fonts]] |
| `--页面标题行高` |行高|
| `--页面标题大小` |字体大小 |
| `--页面标题样式` |字体样式，例如普通或斜体|
| `--页面标题变体` |字体变体 |
| `--页面标题权重` |字体粗细|
