此页面列出了 [Properties](https://help.obsidian.md/Editing+and+formatting/Properties) 的 CSS 变量，这是 frontmatter 的 YAML 元数据编辑器。另请参阅 [[Checkbox]]、[[Text input]] 和 [[Multi-select]] 了解与输入类型相关的变量。

## CSS 变量

### 属性容器

这些变量适用于整个属性容器。

|变量|描述 |
| ---------------------------- | ----------------------- |
| `--元数据背景` |背景颜色|
| `--元数据显示编辑` |在编辑模式下显示 |
| `--元数据显示读取` |阅读模式下显示 |
| `--元数据最大宽度` |最大宽度|
| `--元数据填充` |衬垫|
| `--元数据边框颜色` |边框颜色|
| `--元数据边界半径` |圆角半径|
| `--元数据边框宽度` |边框宽度|
| `--元数据间隙` |属性之间的差距|

### 个别属性

这些变量适用于列表中的各个属性。

|变量|描述 |
| --------------------------------------- | ---------------------------------------------------- |
| `--元数据分隔线颜色` |属性之间分隔线的颜色 |
| `--元数据分隔符颜色悬停` |属性时分隔线的颜色（悬停）|
| `--元数据分隔符颜色焦点` |属性时分隔线的颜色（聚焦）|
| `--元数据分隔线宽度` |分隔线宽度|
| `--元数据属性填充` |属性填充 |
| `--元数据属性半径` |属性圆角半径|
| `--元数据属性半径悬停` |属性角半径（悬停）|
| `--元数据属性半径焦点` |属性圆角半径（焦点）|
| `--元数据属性背景` |属性背景颜色|
| `--元数据属性背景悬停` |属性背景颜色（悬停）|
| `--metadata-property-background-active` |属性背景颜色（活动）|
| `--元数据标签背景悬停` |属性标签背景颜色（悬停）|
| `--metadata-label-background-active` |属性标签背景颜色（活动）|
| `--元数据标签字体大小` |属性标签字体大小 |
| `--元数据标签字体粗细` |属性标签字体粗细 |
| `--元数据侧边栏标签字体大小` |属性标签字体大小（侧边栏）|
| `--元数据标签文本颜色` |属性标签文本颜色 |
| `--元数据标签文本颜色悬停` |属性标签文本颜色（悬停）|
| `--元数据标签宽度` |属性标签宽度|
| `--元数据输入高度` |属性输入高度 |
| `--元数据输入文本颜色` |属性输入文本颜色 |
| `--元数据输入字体大小` |属性输入字体大小 |
| `--元数据侧边栏输入字体大小` |属性输入字体大小（侧边栏）|
| `--元数据输入背景` |属性输入背景颜色|
| `--元数据输入背景悬停` |属性输入背景颜色（悬停）|
| `--metadata-input-background-active` |属性输入背景颜色（活动）|
