此页面列出了[嵌入文件](https://help.obsidian.md/Linking+notes+and+files/Embedding+files)的 CSS 变量。

## CSS 变量

|变量|描述 |
| ------------------------ | | ---------------------------------------------------- |
| `--embed-max-height` |嵌入最大高度 |
| `--embed-canvas-max-height` |嵌入画布元素最大高度|
| `--嵌入背景` |嵌入背景颜色|
| `--embed-border-end` |嵌入“end”边框，简写属性 |
| `--embed-border-start` |嵌入“开始”边框，简写属性 |
| `--embed-border-top` |嵌入顶部边框，简写属性 |
| `--embed-border-bottom` |嵌入底部边框，简写属性 |
| `--embed-padding` |嵌入填充 |
| `--嵌入字体样式` |嵌入`字体样式` |
