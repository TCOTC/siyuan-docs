此页面列出了编辑器中打开的文件的 CSS 变量。

## CSS 变量

|变量|描述 |
| ------------------------ | | ---------------------------------------------------------------- |
| `--文件行宽` |可读行宽开启时的行宽 |
| `--文件折叠偏移量` |折叠指示器的线偏移宽度 |
| `--文件边距` |文件边距|
| `--文件头字体大小` |文件头字体大小 |
| `--文件头字体粗细` |文件头字体粗细 |
| `--文件头边框` |文件头 `border-bottom` 属性 |
| `--文件头对齐` |文件头文本对齐，使用 `justify-content` |
