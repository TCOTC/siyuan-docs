此页面列出了标签的 CSS 变量。

## CSS 变量

|变量|描述 |
| -------------------------- | ---------------------------- |
| `--标签大小` |标签字体大小 |
| `--标签颜色` |标签文字颜色 |
| `--标签颜色悬停` |标签文本颜色（悬停）|
| `--标签装饰` |标签文字装饰|
| `--标签装饰-悬停` |标签文本装饰（悬停）|
| `--标签背景` |标签背景颜色|
| `--标签背景悬停` |标签背景颜色（悬停）|
| `--标签边框颜色` |标签边框颜色 |
| `--标签边框颜色悬停` |标签边框颜色（悬停）|
| `--标签边框宽度` |标签边框宽度|
| `--tag-padding-x` |标记左/右内边距 |
| `--tag-padding-y` |标签顶部/底部填充 |
| `--标签半径` |标签半径|
| `--标签权重` |标签字体粗细|
