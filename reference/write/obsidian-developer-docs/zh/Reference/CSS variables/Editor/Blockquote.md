本页列出了块引用的 CSS 变量。

## CSS 变量

|变量|描述 |
| ------------------------------------------- | ------------------------------------------- |
| `--blockquote-背景颜色` |块引用背景颜色|
| `--blockquote-边框厚度` |块引用左边框厚度 |
| `--blockquote-边框颜色` |块引用左边框颜色 |
| `--blockquote-font-style` | Blockquote 字体样式（例如普通、斜体）|
| `--blockquote-color` |块引用文本颜色 |
