此页面列出了内联标题的 CSS 变量。

> [!note]
> 要查看内嵌标题，您需要启用 **设置 → 外观 → 显示内嵌标题**。

## CSS 变量

|变量|描述 |
| ---------------------------- | ---------------------------------- |
| `--内联标题颜色` |内嵌标题文本颜色 |
| `--inline-title-font` |内联标题字体系列 |
| `--inline-title-line-height` |内嵌标题行高|
| `--inline-title-size` |内嵌标题字体大小 |
| `--inline-title-style` |内联标题字体样式 |
| `--inline-title-variant` |内联标题字体变体 |
| `--inline-title-weight` |内联标题字体粗细 |
