此页面列出了有序列表和无序列表的 CSS 变量。

## CSS 变量

|变量|描述 |
| ------------------------------------------- | ------------------------------------------------ |
| `--列表缩进` |嵌套项目的缩进宽度 |
| `--列表缩进编辑` |实时预览中的缩进宽度|
| `--list-indent-source` |源代码模式下的缩进宽度 |
| `--列表间距` |列表项之间的垂直间距|
| `--列表标记颜色` |标记颜色 |
| `--列表标记颜色悬停` |标记颜色（悬停）|
| `--列表标记颜色折叠` |折叠项目的标记颜色 |
| `--列表项目符号边框` |项目符号边框|
| `--list-bullet-end-padding` |子弹后的填充|
| `--列表子弹半径` |子弹半径|
| `--列表项目符号大小` |子弹宽度/高度 |
| `--列表项目符号变换` |项目符号“变换”属性 |
| `--列表编号样式` |用于编号列表的“list-style-type” |
