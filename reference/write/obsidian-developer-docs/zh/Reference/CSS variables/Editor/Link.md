此页面列出了链接的 CSS 变量。

Obsidian 支持三种不同类型的链接：

- **已解决的内部链接**链接到现有注释。
- **未解析的内部链接**链接到不存在的注释。
- **外部链接** 链接到外部 URL 或 URI。

## CSS 变量

|变量|描述 |
| ------------------------------------------------ | ---------------------------------------------------- |
| `--链接颜色` |已解决链接文本颜色 |
| `--link-color-hover` |解决了链接文本颜色（悬停）|
| `--link-decoration` |已解决链接文字装饰 |
| `--link-decoration-hover` |已解决的链接文本修饰（悬停）|
| `--链接装饰厚度` |解决链接文字装饰粗细问题 |
| `--链接权重` |链接字体粗细 |
| `--链接未解析的颜色` |未解决的链接文本颜色 |
| `--link-unresolved-opacity` |未解决的链接不透明度 |
| `--link-unresolved-filter` |未解析的链接过滤器，例如`色调旋转` |
| `--link-unresolved-decoration-style` |未解决的链接文字装饰风格|
| `--link-unresolved-decoration-color` |未解决的链接文本装饰颜色 |
| `--link-external-color` |外部链接文字颜色|
| `--link-external-color-hover` |外部链接文本颜色（悬停）|
| `--link-external-decoration` |外部链接文字装饰|
| `--link-external-decoration-hover` |外部链接文字装饰（悬停）|
