本页列出了 [Callouts](https://help.obsidian.md/Editing+and+formatting/Callouts) 的 CSS 变量。

## CSS 变量

|变量|描述 |
| ------------------------------------------ | ----------------------------------------------------------- |
| `--callout-border-width` |标注边框宽度|
| `--callout-border-opacity` |标注边框不透明度|
| `--callout-padding` |标注填充 |
| `--callout-radius` |标注半径 |
| `--callout-混合模式` |标注混合模式，允许嵌套标注的颜色混合 |
| `--标注标题颜色` |标注标题文字颜色 |
| `--callout-title-padding` |标注标题填充 |
| `--callout-标题大小` |标注标题字体大小|
| `--callout-title-weight` |标注标题权重 |
| `--callout-content-padding` |标注内容填充 |
| `--callout-内容-背景` |标注内容背景颜色 |

### 输入颜色

标注类型具有独特的图标和颜色，并且可能有多个别名。

|变量|标注类型 |
| -------------------- | --------------------------------- |
| `--callout-bug` | `错误` |
| `--callout-default` | `默认`、`注释` |
| `--callout-error` | `错误`、`危险` |
| `--callout-example` | `示例` |
| `--callout-失败` | ‘失败’、‘失败’、‘失踪’ |
| `--callout-重要` | `重要` |
| `--callout-info` | `信息` |
| `--callout-问题` ​​| `问题`、`帮助`、`常见问题解答` |
| `--callout-成功` | `成功`、`检查`、`完成` |
| `--callout-summary` | `摘要`、`摘要`、`tldr` |
| `--callout-tip` | `提示`、`提示` |
| `--callout-todo` | `待办事项` |
| `--callout-警告` | ‘警告’、‘注意’、‘注意’ |
| `--callout-quote` | `引用`、`引用` |
