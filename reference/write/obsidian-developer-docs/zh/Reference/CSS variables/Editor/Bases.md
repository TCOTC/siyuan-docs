本页列出了 [Bases](https://help.obsidian.md/bases) 的 CSS 变量。另请参阅 [[Properties]]、[[Checkbox]]、[[Text input]] 和 [[Multi-select]] 了解与属性和输入类型相关的变量。

## CSS 变量

### 基础容器

这些变量适用于整个属性容器。

|变量|描述 |
| ------------------------------------------- | -------------------------------------------------------------------- |
| `--bases-header-border-width` |标题区域周围边框的宽度 |
| `--base-header-height` |包含工具栏的基本标题区域的高度 |
| `--bases-header-padding-start` |开始填充（在 [[Right-to-left\|LTR]] 模式下左侧）|
| `--bases-header-padding-end` |结束填充（在 [[Right-to-left\|LTR]] 模式下右侧）|
| `--bases-toolbar-label-display` |工具栏按钮标签的显示 |
| `--bases-toolbar-badge-display` |工具栏数字徽章的显示 |
| `--base-embed-border-width` |嵌入时基础视图周围的边框宽度 |
| `--base-embed-border-color` |嵌入时基础视图周围的边框颜色 |
| `--base-embed-border-radius` |嵌入时基础视图周围的半径 |
| `--base-filter-menu-width` |过滤器菜单的宽度|
