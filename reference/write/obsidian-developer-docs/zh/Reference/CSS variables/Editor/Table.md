此页面列出了表格的 CSS 变量。

## CSS 变量

|变量|描述 |
| --------------------------------------- | ---------------------------------------------------- |
| `--表格背景` |表格背景颜色|
| `--表格边框宽度` |表格边框宽度|
| `--表格边框颜色` |表格边框颜色|
| `--表格单元格垂直对齐` |单元格垂直对齐 |
| `--table-white-space` |表 `white-space` 属性 |
| `--表头背景` |表格标题背景颜色|
| `--table-header-background-hover` |表格标题背景颜色（悬停）|
| `--table-header-border-width` |表格标题边框宽度|
| `--表头边框颜色` |表格标题边框颜色 |
| `--表头字体` |表格标题字体系列 |
| `--表头大小` |表格标题字体大小 |
| `--表头重量` |表格标题字体粗细 |
| `--表头颜色` |表格标题文本颜色 |
| `--表格行高` |单元格文本的行高 |
| `--表格文本大小` |单元格字体大小 |
| `--表格文本颜色` |单元格文本颜色 |
| `--表列最大宽度` |列最大宽度|
| `--table-column-alt-background` |交替列背景颜色|
| `--table-column-first-border-width` |第一列左边框宽度 |
| `--table-column-last-border-width` |最后一列右边框宽度|
| `--table-row-background-hover` |行背景颜色（悬停）|
| `--table-row-alt-background` |交替行背景色 |
| `--table-row-alt-background-hover` |交替行背景颜色（悬停）|
| `--table-row-last-border-width` |最后一行底部边框宽度|
| `--表选择` |选择背景颜色|
| `--表选择混合模式` |选择混合模式 |
| `--表格选择边框颜色` |选择边框颜色 |
| `--table-selection-border-width` |选择边框宽度 |
| `--table-selection-border-radius` |选择边界半径|
| `--table-drag-handle-background` |拖动手柄背景颜色|
| `--table-drag-handle-background-active` |拖动手柄背景颜色（活动）|
| `--table-drag-handle-color` |拖动手柄图标颜色|
| `--table-drag-handle-color-active` |拖动手柄图标颜色（活动）|
| `--table-add-button-background` | “添加”按钮背景颜色|
| `--table-add-button-border-width` | “添加”按钮边框宽度|
| `--table-add-button-border-color` | “添加”按钮边框颜色|
