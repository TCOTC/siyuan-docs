此页面列出了代码的 CSS 变量。

## CSS 变量

|变量|描述 |
| -------------------- | -------------------- |
| `--代码背景` |代码背景颜色|
| `--代码空白` |代码`空白` |
| `--代码大小` |代码字体大小|

### 语法高亮

> [!note]
> 由于 Obsidian 使用两个不同的库进行语法突出显示 - 一个用于编辑视图，另一个用于阅读视图 - 两者之间的样式可能不完全匹配。

|变量|描述 |
| -------------------- | ------------------------ |
| `--代码正常` |非突出显示语法 |
| `--代码注释` |评论 |
| `--代码函数` |功能|
| `--代码重要` |重要的是，正则表达式 |
| `--代码关键字` |关键词|
| `--代码运算符` |运营商|
| `--代码属性` |属性 |
| `--代码标点符号` |标点符号|
| `--代码字符串` |字符串|
| `--代码标签` |标签、符号、常量 |
| `--代码值` |价值观 |
