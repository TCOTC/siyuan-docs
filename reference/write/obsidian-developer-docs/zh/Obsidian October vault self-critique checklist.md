> [!INFO] 提醒
> 尽管我们在下面提出了一些方法来维护和改进您的保管库，但您的保管库的用户很可能就是您，而且只有您。这与插件和主题不同，我们可以提出相对更客观的建议。
> 
> 因此，请随意从清单中删除任何对您来说没有意义的内容并添加您自己的项目。

## 金库维护

- [ ] 您的保管库履行其应有职责的情况如何？ （您的保管库/笔记的用途是什么？您可以使用什么措施来判断它的工作效果如何？）[^1]
- [ ] 您多久能找到一周前使用过的笔记？
- [ ] 如果你的猫故意删除了你的所有文件，你的备份是多久之前的？
- [ ] 您需要记录有关您的工作流程的任何内容吗？写下你的工作方式并为重要但不常见的任务创建清单可能会非常有帮助。

## Vault 维护清单

- [ ] 删除未使用的附件
- [ ] 删除或重构未链接或标记或位于文件夹中的注释（“孤立”注释）
- [ ] 删除未使用的标签
- [ ] 删除空文件夹
- [ ] 处理收件箱笔记/文件夹/标签中的项目
- [ ] 为常用片段或笔记类型制作模板
- [ ] 删除未使用的插件
- [ ] 删除未使用的主题
- [ ] 删除未使用的片段
- [ ] 添加注释中缺少的属性
- [ ] 在适当的情况下将标签转换为属性
- [ ] 修复损坏的链接
- [ ] 浏览插件库以获取新想法

## Vault 重新发现的想法

- [ ] 打开反向链接和传出链接，查看是否有任何有意义的未链接提及
- [ ] 在文件资源管理器中按“修改时间（从旧到新）”对文件进行排序，查看排名靠前的文件并了解如何改进它们。
- [ ] 启用随机笔记核心插件，随机访问一些笔记以获得惊喜。


[^1]：记住“快乐”是一个有效的衡量标准！
