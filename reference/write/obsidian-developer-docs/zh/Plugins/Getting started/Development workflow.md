每次修改插件源代码后，都需要重新加载插件。你可以退出并重启 Obsidian，但很快就会觉得繁琐。

## 在 Obsidian 内重载插件

你可以在已安装插件列表中重新启用插件来完成重载：

1. 打开 **设置**。
2. 点击 **社区插件（Community plugins）**。
3. 在 **已安装插件（Installed plugins）** 下找到你的插件。
4. 将开关拨到关闭以禁用插件。
5. 再将开关拨回打开以启用插件。

现在你运行的已是更新后的插件版本。

## 在文件变更时重载插件

[Hot-Reload](https://github.com/pjeby/hot-reload) 插件会在源代码变更时自动重载你的插件。

更多信息见论坛公告：[面向开发者的插件发布：热重载正在开发的插件](https://forum.obsidian.md/t/plugin-release-for-developers-hot-reload-the-plugin-s-youre-developing/12185)。
