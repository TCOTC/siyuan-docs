# Getting started: documentation best practices for developers

想为项目写文档的开发者？你来对地方了（双关 *write*）。

本页按不同情境，帮你找到相关的文档最佳实践。

## Writing documentation as an open-source developer

你开源了很棒的代码，但别人知道怎么用吗？好的文档能显著提高项目被发现与采用的概率。

如果你是开源开发者，请参阅 [如何撰写软件文档](beginners-guide-to-docs.md) 获取可上手的建议。

## Justifying documentation as a developer at a company

如何在排期里为文档争取时间？测试都写不完，文档又常被拖到最后。

若希望向管理层说明文档价值，并获得在公司内落地文档方案的路线图，请参阅 [在公司内建立文档共识](mindshare.md)。
