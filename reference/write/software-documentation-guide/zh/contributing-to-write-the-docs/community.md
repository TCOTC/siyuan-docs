# 文档社区

我们正在把关心文档的人们聚成一个社区。社区需要「第三空间」来相聚，我们希望成为这样的地方。目前大家可以通过 IRC 频道与邮件列表建立联系：

> - Freenode IRC 上的 [\#writethedocs](http://webchat.freenode.net/?channels=writethedocs)
> - Write the Docs [邮件列表](https://groups.google.com/forum/?fromgroups=#!forum/write-the-docs)
> - Write the Docs [Twitter](http://twitter.com/writethedocs)
> - Write the Docs [GitHub](https://github.com/writethedocs)
> - Write the Docs [Slack](../write-the-docs-resources/slack.md)

## 参与维护

若没有人维护标准、推动实践进步，社区便难以持续。欢迎在 [GitHub](https://github.com/writethedocs) 上为本站及社区其他部分贡献力量。无论你带来的是大胆想法、务实建议还是成熟经验，我们都乐于倾听。
