# 愿景

世界上有一群「文档人」（documentarians）。在此之前，他们缺少一个彼此结识、凝聚成社区的中心场所。我们提供线上与线下的空间，让这件事成为可能。

现在，所有技术从业者都应当关心文档。我们使用日常工具时，已经忍受糟糕的说明太久；人们理应要求所依赖的事物配有扎实的指引。

## 写作者

文档是你向世界分享创作成果的方式。若希望他人从你的工作中受益，他们必须能够真正用上它。帮助我，也帮助你：行动起来，改变现状。

**我们相信：人们应当能轻松开始撰写文档；应当有直截了当的入门指引与好用的工具。**

## 学习者

想学习的人应获得尽可能好的工具。我们希望提升文档的整体水准，让学习想做的事变得更简单。

**我们相信：文档领域应当存在最佳实践；它们应简明、可执行、易于遵循。**

**我们相信：知识应对所有人开放，无论其首选语言为何；文档的写作方式应便于翻译。**
