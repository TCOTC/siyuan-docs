# UX writing

UX writing 指为软件界面中的可见文案而写作：按钮、标签、错误提示等——也就是引导用户完成任务的「微文案」（microcopy）。

正如 Lisa Sanchez 在 [Medium](https://medium.com/@lmsanchez/what-is-ux-writing-1eb71b0f0606) 上所写：「它在设计产品与用户的对话……优秀的 UX writing 与优秀写作共通之处包括：清晰、一致、精确、自我觉察、大量修改，以及对语境与受众的细致关注。」

换句话说：UX writer 的技能集与技术写作者高度重叠，常常由同一人承担。若你想转向 UX writing，下列资源可作为入门（并不穷尽）：
