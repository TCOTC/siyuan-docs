# Accessibility guidelines: for writing and beyond

无障碍写作意味着：让读屏软件能正确朗读文本、信息结构清晰、强调样式与配色可读，等等。

无障碍是优秀 Web 项目的重要部分，文档也不例外。正如一位倡导者所说：「……若内容设计简单、精炼、清晰，你已经在无障碍与本地化方面做了大量工作。」术语 `a11y` 是一种数字缩写，表示 accessibility（a 与 y 之间有 11 个字母）。

另请参阅[减少写作中的偏见](reducing-bias.md)以及[风格指南](style-guides.md)。
