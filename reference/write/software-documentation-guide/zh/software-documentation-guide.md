# 软件文档指南

本指南汇集了 Write the Docs 社区在撰写软件文档与技术写作方面的最佳实践。指南最初面向开发者，帮助大家理解文档、彼此说明文档工作；此后 Write the Docs 的关注点与社区范围都已扩大。

**这是一份持续更新的指南。** 若你愿意贡献内容，请参阅[参与本指南的说明](./contributing-to-write-the-docs/contributing.md)。
