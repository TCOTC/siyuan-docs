# Search engine optimization (SEO) for documentation

## What is search engine optimization?

搜索引擎为许多公开发布的文档站点带来可观流量。搜索引擎优化（SEO）指通过一系列手段提升网页在特定关键词下的排名。

要做好 SEO，需要了解搜索引擎用于排序的算法，而这些规则会频繁变化，因此优化策略也需要持续调整。

## SEO for documentation

优秀的技术写作本身与高质量 SEO 的大部分要求一致：

- 使用祈使句、以用户目标为导向的标题。  
- 通过恰当的小标题让文档易于扫读。  
- 做好信息架构与导航层级。  
- 在页面 `<head>` 中包含元数据（如最后修改时间；实现方式取决于你的发布工具链）。  
- 确保文档满足[无障碍标准](../resources-for-creating-documentation/accessibility.md)。
