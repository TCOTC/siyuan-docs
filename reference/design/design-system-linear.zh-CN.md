# 受 Linear 启发的视觉设计系统

## 1. 视觉主题与氛围

Linear 官网是「深色优先」产品设计的范本：近乎纯黑的画布（`#08090a`），内容像星光一样从暗处浮现。整体印象是极度精密的工程感：每个元素都处于精心校准的明度层级中，从几乎看不见的边框（`rgba(255,255,255,0.05)`）到柔和、有光感的文字（`#f7f8f8`）。这不是把浅色设计「涂成深色」——而是把深色当作原生介质，用白色透明度的细微梯度来管理信息密度，而不是靠色相变化。

字体系统完全基于 Inter Variable，并全局启用 OpenType 特性 `"cv01"` 与 `"ss03"`，使字形更干净、更几何。Inter 的字重跨度很大——从 300（轻量正文）到 510（中等偏上，Linear 的标志性字重）再到 590（半粗强调）。510 尤其有辨识度：介于常规与 medium 之间，形成不张扬的强调。在展示级字号（72px、64px、48px）下，Inter 使用较强的负字距（-1.584px 至 -1.056px），形成紧凑、有权威感的标题，更像「工程产物」而非单纯「设计排版」。Berkeley Mono 作为代码与技术标签的等宽字体，回退为 ui-monospace、SF Mono、Menlo。

色彩系统几乎全为无彩色——深色底配白/灰字——仅由单一品牌强调色点缀：Linear 标志性的靛紫（`#5e6ad2` 作背景、`#7170ff` 作交互强调）。该强调色使用克制且有意图，仅出现在 CTA、激活态与品牌元素上。边框系统采用极细、半透明白边（`rgba(255,255,255,0.05)` 至 `rgba(255,255,255,0.08)`），在几乎无视觉噪音的前提下建立结构，如同月光下的线框。

**关键特征：**
- 原生深色：`#08090a` 营销背景、`#0f1011` 面板背景、`#191a1b` 抬升表面
- 全局 Inter Variable + `"cv01", "ss03"`——几何变体带来更干净的美学
- 标志性字重 510（介于 regular 与 medium）用于多数 UI 文字
- 展示级字号使用较强负字距（72px 时 -1.584px，48px 时 -1.056px）
- 品牌靛紫：`#5e6ad2`（背景）/ `#7170ff`（强调）/ `#828fff`（悬停）——系统中唯一的彩色
- 通篇半透明白边：`rgba(255,255,255,0.05)` 至 `rgba(255,255,255,0.08)`
- 按钮背景接近零不透明度：`rgba(255,255,255,0.02)` 至 `rgba(255,255,255,0.05)`
- 多层阴影，含内阴影变体，在深色表面上塑造纵深
- 以 Radix UI 原语为组件基础（检测到 6 类原语）
- 成功绿（`#27a644`、`#10b981`）仅用于状态指示

## 2. 色板与角色

### 背景表面
- **营销黑**（`#010102` / `#08090a`）：最深背景——首屏与营销页的画布。近乎纯黑，带极淡的偏冷蓝调。
- **面板深**（`#0f1011`）：侧栏与面板背景，比营销黑略亮一级。
- **三级表面**（`#191a1b`）：抬升区域、卡片背景、下拉层。
- **次级表面**（`#28282c`）：最深的浅色暗面——用于悬停态与略抬升的组件。

### 文字与内容
- **主文字**（`#f7f8f8`）：近白，带极淡暖调。默认正文色——非纯白，减轻深色底上的视疲劳。
- **次级文字**（`#d0d6e0`）：偏冷银灰，用于正文、说明与次要内容。
- **三级文字**（`#8a8f98`）：弱化灰，用于占位符、元数据与弱化内容。
- **四级文字**（`#62666d`）：最弱文字——时间戳、禁用态、细微标签。

### 品牌与强调
- **品牌靛**（`#5e6ad2`）：主品牌色——用于 CTA 按钮背景、品牌标识与关键交互面。
- **强调紫**（`#7170ff`）：更亮变体，用于交互元素——链接、激活态、选中项。
- **强调悬停**（`#828fff`）：更亮、更饱和，用于强调元素的悬停态。
- **安全薰衣草**（`#7a7fad`）：偏柔和的靛色，专用于安全相关 UI。

### 状态色
- **绿**（`#27a644`）：主要成功/进行中状态。
- **翡翠绿**（`#10b981`）：次要成功——胶囊徽标、完成态。

### 边框与分隔
- **主边框**（`#23252a`）：实色深边，用于明显分隔。
- **次边框**（`#34343a`）：略亮的实色边。
- **三级边框**（`#3e3e44`）：最亮的实色边变体。
- **细微边框**（`rgba(255,255,255,0.05)`）：极淡半透明白边——默认。
- **标准边框**（`rgba(255,255,255,0.08)`）：卡片、输入、代码块等标准半透明白边。
- **淡线（Line Tint）**（`#141516`）：几乎不可见的线，用于最弱分割。
- **三级线**（`#18191a`）：略可见的分隔线。

### 浅色模式中性色（浅色主题场景）
- **浅背景**（`#f7f8f8`）：浅色模式页面背景。
- **浅表面**（`#f3f4f5` / `#f5f6f7`）：轻微表面着色。
- **浅边框**（`#d0d6e0`）：浅色场景下的可见边框。
- **浅边框替代**（`#e6e6e6`）：更浅的替代边框。
- **纯白**（`#ffffff`）：卡片表面、高光。

### 遮罩
- **主遮罩**（`rgba(0,0,0,0.85)`）：模态/对话框背板——极暗以隔离焦点。

## 3. 字体规则

### 字体族
- **主字体**：`Inter Variable`，回退：`SF Pro Display, -apple-system, system-ui, Segoe UI, Roboto, Oxygen, Ubuntu, Cantarell, Open Sans, Helvetica Neue`
- **等宽**：`Berkeley Mono`，回退：`ui-monospace, SF Mono, Menlo`
- **OpenType 特性**：全局启用 `"cv01", "ss03"`——cv01 提供单层的替代小写 a，ss03 调整部分字形以获得更干净的几何外观。

### 原则
- **510 为标志性字重**：Linear 将 Inter Variable 的 510（介于 regular 400 与 medium 500）作为默认强调字重，在不过分厚重的前提下带来「略加粗」的手感。
- **大字号压缩**：展示级字号逐级收紧字距——72px 为 -1.584px，64px 为 -1.408px，48px 为 -1.056px，32px 为 -0.704px；低于 24px 后逐渐回到 normal。
- **OpenType 即身份**：`"cv01", "ss03"` 不是装饰——它们把 Inter 变成 Linear 的专属字形气质，更几何、更有意图。
- **三层字重体系**：400（阅读）、510（强调/UI）、590（强强调）。300 仅用于刻意弱化的场景。

## 5. 版式原则

### 间距体系
- 基准单位：8px
- 刻度：1px、4px、7px、8px、11px、12px、16px、19px、20px、22px、24px、28px、32px、35px
- 7px 与 11px 暗示用于光学对齐的微调
- 主节奏：8px、16px、24px、32px（标准 8px 网格）

### 网格与容器
- 内容最大宽度：约 1200px
- 首屏：居中单列，纵向留白充裕
- 功能区块：功能卡片常用 2–3 列网格
- 全宽深色区，内部仍限制 max-width
- 更新日志：单列时间线布局

### 留白哲学
- **暗即空间**：在 Linear 的深色画布上，空白不是白——而是「无」。近黑背景本身就是留白，内容从中浮现。
- **标题压缩、周围舒展**：72px 展示字配合 -1.584px 字距显得密而紧，但置于大面积深色内边距中。字形密度与空间慷慨之间的张力构成特色。
- **区块隔离**：各功能区块以较大纵向内边距（80px+）分隔，无可见分割线——深色背景自然形成区隔。

### 圆角刻度
- 微（2px）：行内徽标、工具栏按钮、细微标签
- 标准（4px）：小容器、列表项
- 舒适（6px）：按钮、输入、功能性元素
- 卡片（8px）：卡片、下拉、浮层
- 面板（12px）：面板、重点卡片、区块容器
- 大（22px）：大面板元素
- 全胶囊（9999px）：芯片、筛选胶囊、状态标签
- 圆（50%）：图标按钮、头像、状态点

## 6. 纵深与抬升

| 层级 | 处理 | 用途 |
|-------|-----------|-----|
| 平（Level 0） | 无阴影，`#010102` 背景 | 页面背景、最深画布 |
| 细微（Level 1） | `rgba(0,0,0,0.03) 0px 1.2px 0px` | 工具栏按钮、微抬升 |
| 表面（Level 2） | `rgba(255,255,255,0.05)` 背景 + `1px solid rgba(255,255,255,0.08)` 边框 | 卡片、输入、容器 |
| 内凹（Level 2b） | `rgba(0,0,0,0.2) 0px 0px 12px 0px inset` | 凹槽面板、内阴影 |
| 环（Level 3） | `rgba(0,0,0,0.2) 0px 0px 0px 1px` | 以边框模拟阴影 |
| 抬升（Level 4） | `rgba(0,0,0,0.4) 0px 2px 4px` | 浮动元素、下拉 |
| 对话框（Level 5） | 多层堆叠：`rgba(0,0,0,0) 0px 8px 2px, rgba(0,0,0,0.01) 0px 5px 2px, rgba(0,0,0,0.04) 0px 3px 2px, rgba(0,0,0,0.07) 0px 1px 1px, rgba(0,0,0,0.08) 0px 0px 1px` | 浮层、命令面板、模态 |
| 焦点 | `rgba(0,0,0,0.1) 0px 4px 12px` 及附加层 | 可交互元素的键盘焦点 |

**阴影哲学**：在深色表面上，传统阴影（深上加深）几乎看不见。Linear 以半透明白边作为主要纵深提示。抬升不靠阴影「更黑」，而靠背景明度台阶——每一级略微提高表面背景的白不透明度（`0.02` → `0.04` → `0.05`），形成轻微叠放感。内阴影（`rgba(0,0,0,0.2) 0px 0px 12px 0px inset`）为凹槽面板带来独特的「下沉」感，补足常见深色主题缺少的体量感。

## 7. 建议与禁忌

### 建议
- 所有文字均使用 Inter Variable，并启用 `"cv01", "ss03"`——这是 Linear 字形身份的基础
- 将字重 510 作为默认强调字重——介于中间的标志性选择
- 在展示级字号使用较强负字距（72px 时 -1.584px，48px 时 -1.056px）
- 建立在近黑背景上：营销 `#08090a`、面板 `#0f1011`、抬升面 `#191a1b`
- 使用半透明白边（`rgba(255,255,255,0.05)` 至 `rgba(255,255,255,0.08)`），而非实色深边框
- 按钮背景保持近乎透明：`rgba(255,255,255,0.02)` 至 `rgba(255,255,255,0.05)`
- 品牌靛（`#5e6ad2` / `#7170ff`）仅用于主 CTA 与交互强调
- 主文字用 `#f7f8f8`，勿用纯白 `#ffffff`，以免刺眼
- 采用明度叠层模型：越深 = 背景越暗，抬升 = 背景略亮

### 禁忌
- 勿将纯白 `#ffffff` 作主文字——`#f7f8f8` 可减轻视疲劳
- 勿为按钮使用实色填充背景——系统核心是 rgba 白 0.02–0.05 的透明感
- 勿把品牌靛当装饰用——仅保留给交互与 CTA
- 勿在展示级文字上使用正字距——大字号 Inter 始终偏负字距
- 勿在深色底上使用厚重/不透明边框——边框应为极细的半透明白
- 勿省略 OpenType（`"cv01", "ss03"`）——没有它们只是普通 Inter，而非 Linear 的 Inter
- 勿使用字重 700（粗体）——Linear 上限为 590，主力为 510
- 勿在 UI 壳层引入暖色——色板为冷灰 + 蓝紫强调
- 勿在深色表面上用投影表达抬升——改用背景明度台阶

## 8. 响应式行为

### 断点
| 名称 | 宽度 | 主要变化 |
|------|-------|-------------|
| 小屏手机 | <600px | 单列、紧凑内边距 |
| 手机 | 600–640px | 标准移动布局 |
| 平板 | 640–768px | 开始出现两列网格 |
| 小桌面 | 768–1024px | 完整卡片网格、内边距放大 |
| 桌面 | 1024–1280px | 标准桌面、完整导航 |
| 大桌面 | >1280px | 完整版式、宽裕边距 |

### 触控目标
- 按钮使用舒适内边距，圆角至少 6px
- 导航链接 13–14px，间距充足
- 胶囊标签水平内边距 10px，便于触控
- 图标按钮 50% 圆角，保证圆形、易点按
- 搜索入口位置醒目，点击区域足够大

### 折叠策略
- 首屏：展示字 72px → 48px → 32px，字距按比例调整
- 导航：横向链接 + CTA → 768px 起汉堡菜单
- 功能卡片：三列 → 两列 → 单列堆叠
- 产品截图：保持宽高比，可缩小内边距
- 更新日志：各尺寸保持单列时间线
- 页脚：多列 → 单列堆叠
- 区块间距：80px+ → 移动端约 48px

### 图片行为
- 控制台截图在各尺寸下保持边框处理
- 首屏视觉在移动端简化（更少悬浮 UI 元素）
- 产品截图响应式缩放，圆角一致
- 深色底使截图在任何视口下自然融合

### 迭代要点
1. 所有 Inter 文字必须设置 `font-feature-settings: "cv01", "ss03"`——要做出 Linear 观感，这是硬条件
2. 字距随字号缩放：72px 为 -1.584px，48px 为 -1.056px，32px 为 -0.704px，16px 以下为 normal
3. 三字重：400（阅读）、510（强调/导航）、590（宣告级）
4. 表面抬升靠背景不透明度：`rgba(255,255,255, 0.02 → 0.04 → 0.05)`——深色上避免实色块背景
5. 品牌靛（`#5e6ad2` / `#7170ff`）是唯一彩色——其余为灰阶
6. 边框始终为半透明白，深色底上不用实色深边
7. 代码与技术内容用 Berkeley Mono，其余用 Inter Variable
